Edge ReVanced

Расширения Chrome Web Store, DevTools на телефоне и новая вкладка без MSN в привычном Edge Canary.

Скачать APK Все релизы
Android 10+ и ARM64. Официальный Edge Canary нужно удалить один раз из-за другой подписи. Следующие версии мода ставятся поверх без потери данных.

Браузер, который не требует компьютера

Патчи меняют только нужные сценарии и сохраняют аккаунт, синхронизацию и обычные обновления профиля.

Установка занимает пару минут

  1. Скачайте последний edge-revanced.apk.
  2. Удалите официальный Edge Canary, если он установлен.
  3. Откройте APK и разрешите установку из выбранного источника.
  4. Следующие релизы устанавливайте поверх текущей версии.
